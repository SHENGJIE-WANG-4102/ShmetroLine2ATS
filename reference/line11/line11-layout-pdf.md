# 11号线配线：配线图PDF逐站读取

来源：`reference/上海轨道交通全网配线V2025.26.2.pdf`（单页矢量图，11号线约占图面 x1300–6350、y1600–4900）。2026-11-14 用 PyMuPDF 把 11 号线所在区域按 7–55 倍逐站渲染，并抽取文字层读里程、容量；局部放大图和脚本在忽略目录 `work/line11/`（`tiles/`、`sheets/`），不入库。图例注明「仅绘制有明确资料的配线，且不一定准确」，所以图上没画的不能证明现实不存在。

本文只读图、写文档，不改代码，也不建 `src/data/lines/line11/`。运营含义（哪些车在哪折返、哪里备车）参考 `reference/line11/user-facts.md`，站序参考 `reference/line11/official-timetable.md`；图上读不出来的，不拿这些资料硬补，只在对应条目标可信度或放进“看不清”。

## 怎么读这份文档

- **方向**：按本项目口径，**上行（UP）往花桥/嘉定北，下行（DN）往迪士尼**。图是示意图，不按比例；「站西/站东/站北/站南」指图面上的方位，斜线车站用「西北端/东南端」。
- **右侧行车**：同一段线里，上行和下行各走哪一侧，要看列车在该段的行驶方向，不能一律说「北侧是上行」。最典型的是嘉定北：上行列车是**向东**进终点站，所以**北侧正线反而是下行（往迪士尼）**。下文每条都写明「哪一侧、往哪个方向」，不只写 UP/DN。
- **【假设】方向是推出来的**：图上没有给 11 号线的正线标「上行/下行」箭头。本文的 UP/DN 命名沿用 2 号线、14 号线文档的项目口径（UP 往西北端终点），同一段线里哪一侧走哪个方向按**右侧行车**推。站台、股道、道岔的几何关系不受影响；如果项目以后把 11 号线的 UP/DN 定义反过来，只需把这两个词对调，几何结论不用改。下面的「北侧正线=下行」这类话都是这个意思。
- **站台型式**按图上本线颜色（暗红 `#871C2B`，RGB 135/28/43）的站台块判断：45×10 或 10×45 的块是岛式，45×5 或 5×45 的是侧式，斜线上的 38.9×38.9 是岛式、35.4×35.4 是侧式。
- **可信度**：
  - **确定**：放大后道岔、车挡、站台块都清楚，且里程/容量文字对得上。
  - **较确定**：主线连接清楚，个别细节（道岔具体朝向、短尽头长度）靠图面推断。
  - **看不清**：写明是哪一块、看到的两种可能，不猜。

## 二、嘉定新城分叉（重点）

### 图上看到的东西

嘉定新城站在图上是南北向，站台旁的里程注记是「主7+864 / 支0-088」——这是**主线和支线的分界点**：主线从嘉定北下来到这里是 7+864，花桥支线从这里起算，站中心在支线 0-088（即支线零公里前 88 m）。

车站有 **3 个股道、3 个站台面**：

- **西侧股道**（x≈2465）：花桥支线的**到达线**。从花桥方向过来，先沿站台西面往南走，过了站台再并到中间股道。
- **中间股道**（x≈2479）：嘉定北支线的**下行正线**。从白银路下来，穿过岛式站台的东面，继续往南去马陆。
- **东侧股道**（x≈2492）：**上行正线**（往白银路/嘉定北）。站台东侧的侧式站台就靠这条股道。
- **岛式站台**夹在西侧股道和中间股道之间，两个面分别靠这两条股道；**侧式站台**在东侧股道的东面。

### 文字示意图

### 三条股道分别能去哪条支线

| 股道 | 站台面 | 北端接 | 南端接 | 能去的支线 |
|---|---|---|---|---|
| x2465（西） | 岛式西面 | 花桥到达线 B（沿站台西侧往北，再向西去花桥） | 在站南 y2065 并入 x2479 | 只接**花桥**方向；到达后往南只能去马陆 |
| x2479（中） | 岛式东面 | 白银路/嘉定北（下行） | 往马陆/南翔（下行） | 只接**嘉定北**方向；到达后往南去马陆 |
| x2492（东） | 侧式西面 | 白银路/嘉定北（上行） | 往马陆/南翔（上行） | 北端 y1989.9 分出**花桥出发线 A**；也可直行去嘉定北 |

### 分叉怎么汇进来

- **花桥 → 迪士尼（下行）**：走 B 线，从西边过来，沿岛式站台西面往南，停站台，出站后（y2065）并入中间股道 x2479，再往南去马陆。
- **嘉定北 → 迪士尼（下行）**：走中间股道 x2479，停岛式站台东面，直接往南去马陆。
- **迪士尼 → 花桥（上行）**：走东侧股道 x2492，停侧式站台，到站台北端（y1989.9）分出去花桥的 A 线，绕过站台北侧向西。
- **迪士尼 → 嘉定北（上行）**：走东侧股道 x2492，停侧式站台，直行往北去白银路。

### 在嘉定新城折返，两个方向不一样

- **嘉定北方向来的车**：在 x2479 上，站南就有交叉渡线（y2032–2056），可以过到 x2492 再往北，属于**站后折返**（过站台后换线、换端）。
- **花桥方向来的车**：B 线在站南 y2065 才并回 x2479，**在交叉渡线以南**。也就是说，花桥来的车过站台后接不上南侧渡线；常规做法只能在岛式站台西面原地换端，再沿 B 线回花桥，属于**站前折返**。图上没有为花桥方向单独画站后折返线；如果允许在 x2479 上反向退行到渡线再换线，那是另一种非常规走法，是否允许要问运营。
- 这一点会影响「花桥方向的车能不能在嘉定新城站后折返」的判断，已放进最后的重点核对清单。

### 需要特别说明的几处

- **花桥的尾轨不是「花桥停车场」**。花桥站西的两条尾轨是上海11号线的折返尾轨；花桥停车场（28 列位、6B）在站东北，按颜色和 6B 判断属苏州轨道交通11号线（或两市共用），通过灰色预留联络线接上海11号线，见第四、五节。
- **嘉定北的尾轨和城北路停车场是两回事**：尾轨在站东、两正线末端；停车场的两条出入段线在尾轨之前、从北侧正线分出。列车从停车场出来直接进北侧下行正线往西，不需要先进尾轨。
- **安亭那条中间线是「双端中间线」**：两端都有道岔接两正线，两端又都有车挡（车挡在道岔外侧的短尽头）。它和浦三路、云锦路那种「两正线之间的中间线」是同一类画法。
- **三林不是「两侧式」**：它是两座岛式站台夹一条中间折返线，两条正线在站台外侧通过。这样通过车和折返车互不干扰，是小交路折返站的典型布置。
