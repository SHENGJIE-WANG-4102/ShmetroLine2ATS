# 14号线配线：配线图PDF初读

来源：`reference/上海轨道交通全网配线V2025.26.2.pdf`（单页矢量图，2 号线的读法见 `docs/layout-pdf.md`）。本文件由 Claude 2026-10-23 读图整理，和同目录资料包的其他文件分开。里程和站间距是 PDF 文字层取出的，可靠；配线是 2026-10-23 按 2.2 倍渲染目测的**初读**，道岔方向、尽头线长度、站前还是站后，建模前要逐站放大复核。

图例注明「仅绘制有明确资料的配线，且不一定准确」，所以图上没画的不能证明不存在。外部调研资料包（`research/`）写的「里程未查到」「配线未查到」，以这份 PDF 为准补上。

## 补读（2026-10-24，按 2 倍渲染，仍要逐站放大定稿）

- **站间距和维基百科对不上**。维基英文站表的站距（例如封浜—乐秀路 1.61 km、静安寺—黄陂南路 3.07 km、武宁路—武定路 0.97 km）和 PDF 里程差（1721 m、2944 m、761 m）逐段不同，但全长一致（38.18 km 对 38.199 km）。维基全程 67 分钟、平均旅速 34.2 km/h，和官方首末班一致。
- **封浜**：
  - 站西是渡线；两正线继续延伸成尾轨，到车挡为止；
  - 站西还引出封浜车辆段出入段线；
  - 站东有一条线向南拐，接 13号线西延（0+395.995 一带）。
- **临洮路**：站东一组单渡线。
- **真新新村**：前一版读成「站西两组渡线」，**读错了**。用户放大截图看清楚了（2026-10-24）：
  - 站西（定边路方向）两正线之间有**两条中间折返线**；
  - 靠站台那一端经交叉渡线式的双 Y 接两正线；
  - 远端（定边路那头）也各经一组道岔接回正线，道岔外面还有很短的尽头，末端是车挡。
  - 小交路西端就在这两条线上站后折返，不占正线。
  - 这说明 2 倍渲染看不清细节。其他各站的初读，都要放大到能看清道岔和车挡再定。
- **曹杨路、武宁路、武定路、黄陂南路、源深路**：都画成两条站台条，像侧式站台。
- **一大会址·黄陂南路、源深路**：两条站台之间有一条中间线，两端都经道岔接两条正线。
- **歇浦路**：站东（龙居路方向）一组单渡线。
- **蓝天路**：站后（黄杨路方向）两正线之间有两条线。
- **浦东足球场**：站西一组单渡线。
- **桂桥路**：两正线向北进金桥定修段，14号线部分容量 36（8A）。
