# 第一部分：ATO 起步按改造后实测放缓，区间改成牵引—惰行—制动

## 背景

**实测依据（用户决定直接用）**：D61 用的 B 站 02A05 电磁录音（BV1VGZiBPEjt），用户核实录制于 **2025-08-04，金科路—广兰路，车 02113**。2 号线新 CBTC 2024-01-27 投运（`reference/shanghai-lines-signalling-operations.md`），所以是改造后的 ATO 实车。按 `src/data/vvvf.ts` 的定子频率表（4.77 Hz 每 m/s【假设】）算：

| 阶段 | 录音 | 模型现状 |
|---|---|---|
| 起步 0–36 km/h | 0.75–0.82 m/s² | 1.0（`PERF.aMax`，特性曲线平台） |
| 36–52 km/h | 约 0.91 | 1.0→0.75 |
| 52–70 km/h | 0.22–0.55 | 约 0.68→0.45 |
| 0→71 km/h 用时 | 约 29.6 s | 约 24 s |
| 进站制动（约 61 km/h 起） | 约 0.76 | `bPlan` 0.75 |

制动和模型一致，平均率不动。起步低速段比模型温和；起步越温和，加速段损失的时间越多，同样的区间预算下其余部分就得更快。

## 现状问题：巡航时不停地切换（实测）

`work/review-probe/toggle.ts`：工作日 11:00 起 30 分钟、47 列运行中的车，ATO 平均每列切换牵引/惰行/制动约 **4500 次**，99% 的片段 ≤3 s，巡航时每 0.1 s 在惰行和牵引脉冲之间交替（`dynamics.ts::controlAccel` 的 0.25 / −0.05 m/s 门限，1 级没有惰行带）。用户指出：现实 ATS/车载不会频繁加减速，应该有阈值；还要考虑乘坐体验。

## 现实参照

用户看过的 B 站同一视频 p2：0:07–1:37 是**龙阳路→张江高科一整个区间**。频谱上的模式：
- 起步牵引，速度一路上升，高速段加速度越来越小但一直在牵引；
- 然后**一段逆变器完全关断（惰行）**；
- 然后电制动进站，**尾端缓慢降速**；
- p2 中部另一段形态差不多，说明是固定规则。

夜间用户观察「一直稳在 60 左右」，是夜间等级下保速。

## 要的跑法

- 一个区间内 ATO 的阶段：牵引（受 ATO 加速上限和牵引特性）→［到限速或等级速度就保速］→ 惰行 → 常用制动进站对标。
- **用惰行吃富余**：区间预算有余时，先把惰行起点提前（惰行更长），而不是像现在这样压低整段巡航速度；惰行到某个下限速度还吃不完，再降低牵引截止速度。下限写成数据，能从录音量出来就用实测，量不出才标【假设】。D126/D127 的预算调速（`sectionCruise` / `sectionEta`）改成求「牵引截止速度＋惰行起点」，同一套逻辑同时给排图时分和实车用，不能两处各算各的。
- **保速**（到限速、夜间等级）用连续小牵引平衡阻力，不是牵引/惰行交替；坡道上掉速超过一个滞环（数据，比如 3 km/h）才重新加牵引。
- **乘坐体验**：保留 jerk 限制；除 ATP、精确停车外，牵引和制动之间不直接切换，中间至少经过惰行；同一阶段内不来回切。正常运行每区间阶段切换次数在个位数（牵引、惰行、可能一次补牵引、制动、对标）。
- 进站制动开头温和、尾端缓慢降速到对标；常用制动平均率仍按 `bPlan`（与录音 0.76 一致），只调形态。
- **ATO 起步加速度上限**：ATO（含 DTO/AM/ATO 司机按钮发车）请求的牵引加速度不超过 `min(牵引特性, ATO 上限)`。上限作为数据放 `PERF` 或 `OPERATIONS`，约 0.85 m/s²，下载录音后按改造后两段重新拟合，说明取法。注释写依据：用户决定，2025-08-04 改造后实车录音。**人工驾驶（CM/RM）仍按满牵引特性**。
- 人工驾驶的推荐速度（CM 表盘黄三角，D130）跟着新跑法给，不再是一个固定巡航速度；惰行段怎么显示推荐，拿不准先问。
- 夜间等级（D121/D122）保留保速跑法，不改等级参数。
